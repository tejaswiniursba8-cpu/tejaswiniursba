Technologies Used:
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Netlify (Deployment)

1. Home Section
   - Introduction
   - Animated hero section
   - Buttons for contact and projects

2. About Section
   - Personal information
   - Skills and experience
   - Profile image

3. Skills Section
   - Technical skills display

4. Projects Section
   - Portfolio projects with links

5. Contact Section
   - Instagram link
   - LinkedIn link
   - Contact details

Features:
- Responsive design
- Mobile friendly
- Futuristic UI design
- Glow animations
- Smooth scrolling
- Social media integration
- Online deployment

1. Planned website layout

3. Added CSS styling and animations
